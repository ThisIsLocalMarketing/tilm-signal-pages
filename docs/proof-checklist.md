# Proof Checklist

Before any Signal Page or advertiser preview is public, confirm:

- business name correct,
- category correct,
- offer/message correct,
- phone/contact info correct,
- QR/link destination correct,
- tracked redirect and approved action paths tested when measurement is included,
- measurement notice matches the data actually collected,
- issue month and first-Wednesday mailbox target confirmed for Community Cards,
- printer and postal workback schedule supports the target,
- expiration/restrictions correct,
- no prohibited claims,
- no private data exposed,
- proof approval captured before payment request.
